# Optional typed stale-action feedback

The original agent catches `StalePage`, re-observes and retries. When the page and executed history remain unchanged, the model can receive the same input repeatedly. The adjacent `browser-stale-feedback-20261022-01` evidence reproduces this mechanism and verifies eleven identical saved request bodies in the raw03 run. It does not identify the physical guard branch that rejected that actual attempt.

`action_feedback.install(agent_module, model_module)` keeps the original agent and model functions, wrapping the inner `predict` and `act` commands before the outer `tick` catches the typed exception. Four recent records are supplied in the separate `state.action_feedback` field of subsequent policy requests. Each records the attempted operation/target, command-entry page fingerprint, phase and actual change in executed-history length. Physical input outcome remains unknown. Existing page text, elements, questions, actual history, candidate populations and browser guards remain unchanged. The first policy request and text-helper request path are unchanged.

For the existing benchmark, explicitly use `wrap_model_adapter(original_adapter)`. Installation must occur inside `model_adapter`, before policy routing and recording. Wrapping only the upstream loader places insertion after the adapter has rewritten the URL and would omit feedback. A regression exercises the exact original benchmark adapter and checks that the actual sent body, saved model request and saved transport request agree.

Six CPU tests pass using verified original upstream Agent/model source with fake browser and network I/O. They cover pre-input refusal, stale post-input observation, stale prediction without an invented selection, bounded per-agent state, restoration and actual benchmark adapter composition. The source has an independent CLEAR review. No real browser, model, GPU or service was run for this component. It remains a separately selected experimental agent protocol; V7 baselines and Decision3 plans are unchanged, and browser success improvement has not been measured.
