## Read source and mechanism

- [Publisher runtime, exact revision](https://huggingface.co/vllm-sr/d3-edge/blob/cab71e6ad3461b8086d51ddb572c656babd63b0b/d3_runtime.py): `D3.__init__` checks all 255 tokenizer codes/IDs, explicit CPU selects the stock BF16 backbone with `attn_implementation='sdpa'`, then loads the original small FP32 readout. `kernel_report` recursively checks wrapper closures; the original CPU guard stays intact. `PromptEncoder` sends whole-prompt key masks to full-attention layers while DeltaNet retains the stock causal recurrent mask and no cache. `logits` reads the last prompt hidden state, multiplies FP32 hidden/readout, masks unused options and `probabilities` applies temperature/softmax. `loaded_files` excludes only publisher-declared non-runtime files; all 20 runtime files must exist. `verify='full'` checks every runtime hash. The actor authenticates all 20 itself inside the owner before loading source, then invokes this unchanged full verification again.
- Local installed Transformers 5.17.0 `models/qwen3_5/modeling_qwen3_5.py`: `causal_conv1d_fn` uses grouped `torch.nn.functional.conv1d`; `torch_chunk_gated_delta_rule` casts inputs to FP32, normalizes, performs triangular solves and scans chunks, finally restores the input dtype. This is real CPU-compatible tensor math, not a CUDA wrapper. Actual architecture has six full-attention and six linear-attention layers, 12 total, hidden size 1024; the actor checks this against the pinned config.
- Installed Transformers `integrations/hub_kernels.py:use_kernel_func_from_hub_with_fallback` selects original optional packages before the Torch function. `USE_HUB_KERNELS=0` disables Hub kernels but does not by itself disable installed FLA or causal-conv packages. Therefore the actor rejects visible `fla`, `causal_conv1d`, and `kernels`, then inspects all four actual bound convolution/DeltaNet functions and the original publisher report. It does not patch availability checks, imports, bindings, or shared packages. `D3_FAST=0` is an official publisher flag, not a source edit.
- Saved `artifacts/jev-d3-native/20261015-edge-cpu-smoke-01` has historical CPU contract evidence for this revision, with batch eight/two CPU threads and different boundaries. It is source precedent only; the fresh profile inherits no admission, numeric parity, latency, benchmark or browser score.
