# Decision before implementation/execution

Reuse the prior saved CPU findings only as motivation: mapped native decoder mechanics worked, but they did not measure CUDA context, GPU allocation or UMA accounting. The next authorized profile therefore loads no model and reads no model metadata/weights. First separate explicit initialization/synchronization from a deterministic tiny BF16 operator, under a new reviewed owner and unchanged2GiB/30s/CPU0/reserve requirements. These limits do not prove that the probe will fit.

Installed Torch2.13.0+cu130 source was read before implementation: `cuda/__init__.py` for `init`, `_lazy_init`, `get_device_properties`, `is_initialized`, `synchronize`; `cuda/memory.py` for global memory queries, allocator counters, fraction and `empty_cache`; `_C/__init__.pyi` declares a UUID string and the integrated-property attributes; root actual01 later showed UUID is a native `_CUuuid`, so the stub is not a runtime type guarantee. The actual small sources are SHA-selected; native libraries are stat-only.

Key consequences: `mem_get_info` enters cudart and can initialize CUDA, as can property/current-device queries. Pre-init and pre-first-sync stages therefore do not query them. Allocator counters omit some context/driver allocations; global free is not a process-private delta. A64MiB fraction is a caching-allocator control, not a total physical-memory/context cap. `empty_cache` frees unused allocator blocks while the initialized context remains; only the owner closes its authenticated process. No host registration, ctypes, HMM/managed-memory, model, layer, transfer or auto-device-map feature is added.

Primary official APIs were checked along with the root's research: [init](https://docs.pytorch.org/docs/2.14/generated/torch.cuda.init.html), [synchronize](https://docs.pytorch.org/docs/2.14/generated/torch.cuda.synchronize.html), [mem_get_info](https://docs.pytorch.org/docs/2.14/generated/torch.cuda.memory.mem_get_info.html), [set_per_process_memory_fraction](https://docs.pytorch.org/docs/2.14/generated/torch.cuda.memory.set_per_process_memory_fraction.html), [empty_cache](https://docs.pytorch.org/docs/2.14/generated/torch.cuda.memory.empty_cache.html). The stable URLs redirected to2.14;2.13 pages were inaccessible through the browsing tool. These docs support the general API meanings, while the pinned installed2.13 sources govern the actual probe. No API was executed during preparation.
