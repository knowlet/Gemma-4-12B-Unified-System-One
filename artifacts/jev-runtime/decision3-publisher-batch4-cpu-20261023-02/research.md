# Reuse and source provenance

The implementation reuses local immutable source rather than adding a framework. Native01 actor (`ec38584c...`, 27,032 bytes) already contains the one-constructor publisher loader, genuine batch4 backend, CPU/BF16/FP32 checks, full-context rejection, original ordering, shape-only hook and full model/runtime authentication. Its `source_audit.py` and historical `publisher-source-audit.json` are copied byte-identically. The recorded publisher `d3_runtime.py` AST identity is retained as metadata; this preparation does not reopen the referenced model source, tensors, tokenizer or native runtime payloads.

The source-only resource closure found an inherited R+3GiB host gate in the frozen Lite utility actor (`33859d8b...`, 24,848 bytes). Changing only the outer owner would leave that gate inconsistent. The minimum extraction keeps Deadline, binding_identity, check_record, diagnostic, ensure_elapsed, finalize_state, host_gate, owned_limits, process_identity, read_json, require, sha, unique and write_json. ROOT, reserve, runtime interpreter, overlay, CPU/start environment, kernel names and version globals retain their ASTs; only MEMORY_MAX changes 3GiB to 2GiB. host_gate changes only its diagnostic wording in addition to the global cap. The old Lite words in failure-evidence diagnostics are deliberately retained to keep the helper function ASTs identical. There is no Lite model entry or monkeypatch.

Owner06 is a separately reviewed fixed 2GiB/10,800-second successor. Its controller and freeze are pinned by the Edge plan, and the root's independent owner06 source review is referenced by source-provenance.json. Original owner05/3GiB and owner03/7,200-second sources remain unchanged.

A separate source finding concerned inherited native smoke success timing. Native01 returned inside watchdog/finally scopes, permitting late cleanup/final writes to escape its existing monotonic success checks and permitting cleanup to replace an original exception. Root explicitly authorized a narrow control-flow repair while this successor was unfrozen. The candidate adds DeadlineScope, places successful call/whole gates after cleanup, accounts for execute preflight in the existing 120 seconds, and demotes late/cleanup failures while retaining a prior error. The publisher constructor, runtime loader, backend, shape hook, native validation and authentication ASTs remain identical. No threshold, context, numerical path, batch size, source/data rule or external authority was weakened.

The original two tests that reopened model publisher sources are represented by the preserved historical audit and replaced here with local immutable-source AST/extraction tests. The other eight original native fake tests, five resource/AST tests and seven timing tests run without model/runtime/native/host/unit/observer/network/Git access. Exact outcomes and baseline assertions are saved in validation.json, static-tests.log and baseline-regression.json.

This is source preparation only. Root/another peer must independently review the authored extraction and material timing fix. Future actual qualification must use this exact Edge plan and helper, a fresh owner06 admission and fresh outputs/cache, with genuine final authentication and whole-unit closure. Prior 3GiB smoke, performance, memory, quality and browser evidence cannot qualify this 2GiB candidate.
