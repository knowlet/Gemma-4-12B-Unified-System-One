Source-only shared CPU text helper, 2026-10-23.

This isolated implementation supplies a genuine native-generation path for the existing `jev_ultrafast` field helper boundary. It selects **official Qwen2.5-0.5B-Instruct**, revision `7ae557604adf67be50417f59c2c2f167def9a775`, BF16, CPU, four inference threads. It does not change a benchmark, task, judge, option, agent loop, active owner, or ComfyUI source/state. There is no model-dependent helper routing.

`helper.py` imports only stdlib until an explicit future `load_runtime` call. Its default invocation prints `source_only_not_ready` and starts no model, socket, server or browser. The production factory requires the exact owner-bound runtime returned by the loader and a durable new-directory journal. The separate internal application engine accepts test doubles only for the clearly labelled fake tests; passing an arbitrary fake runtime to the production factory is refused.

The loader is intentionally **blocked by the pending selection**. The ASGI application exposes only bearer-authenticated loopback POST `/chat/completions` and `/v1/chat/completions`. An external runner must bind **127.0.0.1** and retain readiness/exit evidence; this code does not start an ASGI server. The original two message objects/content pass directly to the native chat template. In the browser client, retain `TEXT_MODEL_REASONING=none`; use the existing `--text-endpoint`, `--text-model`, `--text-api-key-env` options. The 25-second original client/retry behavior remains unchanged.

Generation is native **unconstrained greedy** inference: one sequence, 128 new tokens, an 8192-token combined prompt/output limit, no truncation, no sampling, one beam and native KV cache. Returned prompt IDs and streamed/returned generated IDs must agree. Only an actual configured final EOS can succeed; an earlier EOS, a length stop, malformed tokens or hook/decoder failure refuses. EOS itself remains in usage/raw-token evidence, while only that final EOS is omitted from strict native decoding. Special tokens and significant whitespace are not stripped. The decoded whole string must parse to exactly one nonempty `text` string of at most 2000 characters. Duplicate keys, nonfinite numbers, fences, commentary, extra keys, null and repair attempts refuse. The incoming context's goal/field/page/history is validated but is never used by code to compute a field value. There are no fixtures, benchmark tasks, gold values, DOM strings or task-name matching rules in this source.

Every request uses its original monotonic entry time. Queueing, receive, original-body retention, template/tokenization, forwards/token callbacks, decode, generation retention, response retention and final publication checkpoints share **20 seconds**. Journal returns mean bytes and the containing directory entry were fsynced. Evidence failure latches the service closed. Native failures retain observed partial token IDs when available. Cancellation is propagated. A candidate is retained with `client_delivery=unknown` before any HTTP publication; a late start never receives the candidate body, and a partially started response never gets a replacement body.

The **last cooperative authorization boundary is immediately before the ASGI response-body send**, after all candidate retention and another owner/deadline check. The awaited send also has the remaining-time timeout and its completion is checked. A blocking native forward or an ASGI send that already queued bytes cannot be interrupted/retracted by these Python checks. The fake late-body test explicitly demonstrates this limitation; no hard 20-second runtime guarantee is claimed. A separate authenticated external owner/controller must enforce the deadline, retain terminal/kill evidence, supervise listener/PID/start/cgroup/cap/reserve/swap/ComfyUI checks and join browser delivery evidence.
