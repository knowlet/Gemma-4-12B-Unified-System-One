# Mapped native decoder CPU fixture

Prepared source only: no Torch import, real tensor payload read/hash/mmap, model or actor run occurred during preparation. The preceding header inventory used only the 8-byte prefix, 88,952-byte JSON header, small config/source files and stat. See `research-decision.md` and `header-selection.json` for the exact layer0/sliding and layer5/full inventory.

`fixture.py` is dry by default. The reviewed parent owner supplies the same explicit CLI as the prior tiny fixture, profile `bf16-real-layer-cpu-fixture-v1`, pinned four-key `selection.json`, a fresh output and sealed `JEV_LAYER_DEADLINE_MONOTONIC`. Package versions are Torch2.13.0+cu130, Transformers5.17.0 and safetensors0.8.0. Twenty-two small source references are hashed; five native libraries and the canonical checkpoint have stat identity only. The historical full checkpoint SHA is preserved and never recomputed by this profile.

On an authorized run, the actor processes the two native decoder layers sequentially, with the original48-layer config. It constructs only each selected decoder on meta, strictly assigns its actual BF16 selected parameters **and buffer**, and proves every pointer against its expected file offset and `/proc` VMA inode/device. No cloned weight baseline, embedding/lm_head, full model or complete-model state dictionary is built. Synthetic inputs of1/32 tokens each run twice through original CPU RoPE, native mask builders and original SDPA adapter. The reversible observation wrapper passes the same arguments to SDPA and restores its instance-local registry entry; it does not claim a particular native kernel. Matching output-byte hashes prove repeat determinism only. Raw hidden states and weights are not saved.

The actor streams hashes over the27 selected state ranges before/after, not their20GB combined envelope. This **prefetches/warms** pages, so first-forward timings are not cold measurements. Hashing and forward times are separate. Application requests are restricted to selected byte ranges; kernel page-level read-ahead may touch adjacent bytes. No cache eviction, `drop_cache` or `fadvise` is used. Fault counters do not establish disk-read volume.

Each stage writes bounded JSON with elapsed time, faults, process RSS/Anon/File and its own cgroup memory.current/peak/stat. Stages cover before/after meta construction, strict assign, each forward and explicit deletion of weights/layer/handle plus GC. These are sequential, non-atomic observations; deletion and GC do not prove page-cache reclamation. The25-second parent deadline is cooperative; the owner's separate30-second hard limit remains authoritative.

All four planned cases, each with two finite identical repeats, unchanged mapped-state snapshots, selected range hashes, source/header checks and restored interfaces are required for exit0 (`completed_mechanism_observations`, `passed=true`, `completed=true`). Insufficient time preserves completed cases, current range-hash progress and stage files, writes `partial_deadline`, keeps completion flags false and exits2. Other failures exit1 and preserve the primary error plus cleanup evidence. Output names are `intent.json`, numbered `stage-*.json` and `receipt.json`; no tensor output file is generated.

CUDA is hidden before import. Actual availability/count queries are recorded and required to return False/0; wrapped work APIs refuse calls. Monitoring begins after Torch import and does not cover all native calls. This CPU-only profile cannot qualify GPU transfer, UMA,12B loading,8192 context,20-second workloads,N3/Q95 equivalence,browser usefulness or benchmark scores. A later successful actor run would still require separate interpretation of the saved observations.

Preparation validation:17 stdlib tests passed in0.081 seconds; Ruff check passed. Temporary tests use impossible live metadata and synthetic text bytes only. Static/stub success does not establish real-layer numerical, storage or runtime success. Actor/test/header/selection source pins are frozen pending independent review; the source preparer does not launch the actor.
