Predeclared canary interpretation: correctness in the six cells is only a
self-authored sanity observation. A semantic error that changes with option
order suggests position sensitivity, not proof of an encoding bug. Stable wrong
semantics suggests a model/prompt-domain problem but does not establish its cause.
Any missing head, label mismatch, nonfinite distribution, late return, or source
change is an execution/contract failure, separate from semantic diagnostics.
