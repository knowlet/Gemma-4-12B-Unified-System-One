## Current-source GGUF runtime contract

Use the committed source revision as `--runtime-source-revision`. Historical
commands and measurements in [the reproduction guide](gguf-release.md) remain
bound to their original revisions and do not qualify this new runtime.

The bundled direct `.venv/bin/python scripts/gguf_adapter.py ...` command selects
its own Python environment. Custom Python adapters require `--runtime-python`
with the same executable spelling as the first adapter command argument.
Shell and `uv run` wrappers are rejected rather than being attributed to the
wrong interpreter. Virtual environments remain distinct even when they share
the same underlying Python binary.

The guard hashes the committed `uv.lock` plus actual installed distribution
files, including native extensions and additional files inside distribution
owned directories. Versions and RECORD text alone are insufficient. Missing
wheel inventories/files fail closed. Only this checkout's editable
`gemma-system-one` distribution is allowed; project sources are pinned separately.
Generated bytecode is excluded. Rechecks run between populations and before
publishing the calibrated sidecar, outside backend-call latency measurements.
Use a minimal frozen environment; complete file hashing adds real I/O.

Runtime receipt schema 2 records file, Python-environment and combined
implementation digests. The new sidecar binds the combined digest. This records
actual bytes alongside the lockfile, not an attestation that every installed
wheel was produced from that lockfile. Dependency installation still belongs to
`uv sync --frozen`. The guard assumes a controlled immutable workspace, not a
compromised interpreter, hostile import hooks, arbitrary external Python paths,
or concurrent filesystem attackers. Bind custom extra inputs with
`--runtime-file`.

The report output must be outside model, capture and dataset directories and
must not alias a protected input, including via symlinks or hardlinks. Rejection
occurs before the error-report write path. Calibrated prediction streams SHA256
over the selected language model and projector at startup; equal sizes no
longer identify weights.
