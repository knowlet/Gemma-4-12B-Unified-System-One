# Long-page navigation after the fixed V7 comparison

The completed V2 run remains **4/10**, including the curl and PubMed failures. The [saved-evidence diagnosis](../../artifacts/jev-runtime/v2-public-failure-diagnosis-20261022-01/summary.json) joins actual model requests to their request-time observations. A target present in a saved intermediate curl snapshot was absent from every actual request after a fresh observation replaced that snapshot. The model then scrolled fifteen times. This supports investigating observation and navigation capability; it does not prove that every possible sixteen-step route was impossible, or that the model ignored an offered target.

PubMed's initial page visibly said Forbidden and offered no form or filter elements. Waiting sixteen times made no progress. The saved network ledger does not establish the actual HTTP status or its cause. Keep this task in the denominator and distinguish page availability from the model's response to it.

The larger Browser Use project provides a useful reference: [find_text](https://github.com/browser-use/browser-use/blob/aa093a843da5edbf323c0b4145c9b6a0db3ecde8/browser_use/tools/service.py#L1504) scrolls to supplied text through a browser event, while [search_page](https://github.com/browser-use/browser-use/blob/aa093a843da5edbf323c0b4145c9b6a0db3ecde8/browser_use/tools/service.py#L1311) searches page content through CDP. The inspected source is pinned to `aa093a843da5edbf323c0b4145c9b6a0db3ecde8`, SHA256 `25746ddfe719c0a800b2b4fcc399aea4fc8be20c48b04ab4118841fd5419eb73` (93,504 bytes), under its [MIT license](https://github.com/browser-use/browser-use/blob/aa093a843da5edbf323c0b4145c9b6a0db3ecde8/LICENSE). The current find-text error path returns explanatory content rather than a typed error, so failure feedback requires separate care.

A future experimental agent profile could expose a generic find-on-page operation, with the model choosing its search text from the task and current observations. It must report actual search failures and stale observations, preserve native action guards, and avoid task-specific routes or judge access. Test long pages and failed searches before a complete browser run. The fixed V7 baselines and Decision3 comparison retain their existing actions, budgets and judges; a new capability needs its own label and matched model comparisons. No implementation or score improvement is claimed by this research note.
