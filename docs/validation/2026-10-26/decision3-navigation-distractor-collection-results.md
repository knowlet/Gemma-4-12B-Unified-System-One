# Complete navigation-distractor TRAIN collection and GPU features

The corrected native event checker completes all **24 independent TRAIN
scenarios**, producing **72 intact original publisher wires**. A fresh process
independently replays collection admission, all observed actions and the exact
wire projection. The complete collection is accepted for feature extraction.
It is not a model prediction, an optimizer authorization or a benchmark score.

This addresses a concrete coverage gap from the earlier
[failed two-head browser run](decision3-goal-routed-two-head-gpu-browser-results.md):
the candidate selected unrelated navigation from a 13-choice CLICK menu, while
its CLICK-target training menus contained only four or five choices. That gap
does not by itself prove the cause of the model error.

There are **288 native heads and 2,075 legal criterion positions**. These counts
come from the original publisher wires, including every offered target, rather
than the fixture's authored node counts. Teacher actions comprise 33 CLICK,
9 TYPE_TEXT, 6 SELECT and 24 DONE. Original head order, operation spellings,
instructions, histories and complete menus remain intact. There is no target
padding, filtering, remapping or alias normalization.

The collection uses the existing settled V7 observation profile, frozen public
collector and a source-bound extension for this new scenario profile. The
original default profiles stay unchanged. These new local scenes were authored
for TRAIN; no browser evaluation goal or prediction is copied into the corpus.
Feature-only requests contain no teacher labels. Separate teacher annotations
remain outside the original wires, and every original target loss mask remains
false. Fitting requires a separate explicit dataset authority.

The browser collection takes 13.008069964009337 seconds under the original
five-core, 8 GiB, zero-swap owned boundary; its selected command takes
11.25709327502409 seconds. Independent verification checks 195 frozen source
files, 93 captured source files, 19 original owner sources and 369 total file
identities. It checks both original live process identity samples, original
scoped unit/cohort closure and current unit/cgroup absence. No model is loaded
and no model call is made.

The earlier 24-scene attempt and its 62 partial rows remain quarantined. The
[event-fix diagnosis](decision3-navigation-distractor-native-event-fix.md) explains
its three false rejections; none of those partial rows are reused. One initial
post-collection audit rejects a relative-path session receipt. A separate
receipt preserves the same original session and file hashes with absolute path
spelling, and a new audit changes only that receipt filename. The collection
itself is not rerun or altered for this metadata correction.

## Genuine GPU feature verification

One genuine d3-edge load processes all 72 accepted full wires. The BF16 encoder
and frozen FP32 readout remain unchanged. Independent stdlib FP64 replay
computes all 255 logits for each of the 288 native heads, then checks all 2,075
legal probabilities, ordered argmax choices and entropy confidence. The maximum
absolute probability error is 3.4793564546165e-7, within absolute 1e-6 plus
relative 1e-5; every ordered argmax matches. Every head uses its own actual
same-call feature row, with no padded or substituted target menu.

The original GPU owner takes 61.01481958903605 seconds; its selected command
takes 59.44683157798136 seconds, within the unchanged 120/113-second limits.
Model loading takes 3.331493175996002 seconds. Peak CUDA tensor allocation is
2,385,853,440 bytes and peak reservation is 6,320,816,128 bytes; the allocator
starts and ends at zero. Independent review checks 32 original owner sources,
130 leaf source entries, all 21 publisher load files and 400 total artifact
identities, as well as original scoped closure and current unit/cgroup absence.

No teacher labels, trained delta, candidate composition or optimizer are opened
during GPU capture or its independent replay. Feature acceptance leaves fitting,
model, browser and benchmark qualification false. These are TRAIN features and
numerical checks, not a new prediction accuracy or browser success result.
