# Decision3 Edge observed browser results

On 2026-10-22, Decision3 Edge produced **0/10** successful tasks on the original V7 Chromium suite: known4 0/4 and public6 0/6. All ten tasks received BLOCKED outcomes without task errors. Neither group was rerun. The pinned publisher-native BF16 model used its complete 255-code readout, native batch eight, temperature one, context 8192 and the publisher text48 warmup.

The observed task score is available, while **execution completion and model qualification remain false**. After the last task, host monitoring stopped the selected public6 actors because it could not identify a short-lived system process. The sanitized host log identifies that process as the crash reporter started by a failed constrained Ruff check. These checks are now kept outside actual model runs; the host and Comfy protections remain unchanged. Public6 lacks its final actor, transport and cache/runtime receipts. A later read-only check confirmed the selected actors, observed cohorts and cgroups absent; this does not replace the missing final receipts.

All twelve client HTTP attempts join to twelve admitted HTTP 200 gateway responses and complete native journals, with exact request, response and status matches. The unchanged browser scorer, both V7 bundles and 39 selected source hashes were checked. A separate saved-output semantic replay of known4 found all fifteen question heads intact and the native model already choosing BLOCKED; the interface did not introduce that answer. No raw DOM, requests, answers or weights are included in the published aggregates.

Edge used the qualified BF16 Q95 text helper; Gemma’s completed 4/10 V2 result used an in-process NF4 helper. This comparison does not establish a matched cross-model win. The remaining Decision3 checkpoints and a Gemma control with the same Q95 helper are still pending. The largest model’s original conservative memory floor exceeds physical RAM; that is a resource-profile refusal, not a quality score or proof that a separately measured streaming loader cannot fit.
