# GX10 CPU 文字 helper 實測準備

已完成並獨立複核兩個來源套件：受限執行環境盤點，以及真正的單一欄位文字生成測試。尚未執行環境盤點或載入模型，沒有新的生成、JevBench或瀏覽器成績。

盤點程式將在原有四核心、3 GiB、零swap限制內驗證九個選定原生檔、十三個來源、模組與Python身分；來源與精確啟動設定已複核，10項假邊界測試通過。這不代表完整間接DSO閉包或模型資格。

生成測試會沿用已凍結helper02的公開loader與factory，在自有工作內建立八檔精確快照、重新驗證內容，透過真正Qwen2.5-0.5B-Instruct產生一個全新合成欄位值。獨立父程序監督實際worker身分與原started+20秒期限，保留原生token／EOS／嚴格JSON與失敗證據；沒有從目標字串推導的備用生成器。此步只測程序內ASGI，實際HTTP服務與原始瀏覽器評測仍是後續工作。

最後複核另修正控制通道的整體讀取期限：前版對每一片段重新給socket等待時間，可能讓完整資料超時後仍讀取成功。新版用同一個單調時鐘絕對期限，涵蓋所有片段與JSON解析。六個新增假時鐘回歸案例保留前版對照，新版共22項假邊界測試、Ruff／AST／dry與獨立複核通過；這些不是22次模型生成。前版來源與審查均保留。
