# V7 與 V7 links：自造網頁短測準備

已知的單例瀏覽器診斷使用 V7，不能用來判定 V7 links 是否改善選擇。新的 source-only 短測在自造的 loopback 頁面建立兩個同名連結，交換目的地順序，並以固定上游 snapshot／model 程式生成 V7 與 V7 links 請求。四次嘗試的順序與分母固定；模型請求、完整可保存回應、失敗及尚未啟動的嘗試交給呼叫者的私有 sink，程式不點擊連結。

以本機 Chromium 和假 loopback 模型端點測試短測及既有 V7 links 觀察契約，共 35 項通過。這僅驗證合成頁面及接線：沒有呼叫真實模型，也沒有真實網站任務成功率、盲測或正式榜單分數。程式預設不可啟用，下一步需要獨立監督的模型端點、硬性期限、來源與收尾證據，再比較兩種觀察設定。
