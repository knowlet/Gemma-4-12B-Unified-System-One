# Decision3：連結目的地觀察設定

日期：2026-10-27

在[單例錯誤點擊診斷](decision3-text-history-click-diagnosis.md)中，原生請求未包含連結目的地。新增獨立的 V7 links 觀察設定，將可見 HTTP(S) 連結的來源與受限路徑加入模型元素及點擊目標；新欄位不含網址憑證、查詢字串或片段，路徑本身仍可能包含識別資訊。這是與原 V7 不同的設定，須分開評測。

新設定把目的地保存在獨立對照表，原本的 actions、索引、選項、頁面指紋、動作執行器與新鮮度檢查維持原樣。來源封裝固定原始版本並支援雜湊核對；[獨立 runner](../../../scripts/jev_browser_profile_v7_links_benchmark.py)必須明確選擇新設定。相關設定、runner 與既有 V7 契約共 56 項本機測試通過。

另在真實 Chromium 的合成 loopback 網頁上比較兩種快照和以假函式回覆的模型請求。測試輸出顯示，原有欄位、四個動作及指紋相同，兩個可見連結的目的地進入新請求；去除新欄位後的模型請求一致。輸出亦記錄瀏覽器和本機伺服器關閉，但未獨立留存該程序的退出碼。測試沒有呼叫真實模型或取得評測分數。

仍需在真實模型及瀏覽器任務中測試，才能判斷目的地資訊是否改善選擇；單例中的錯誤不能證明缺少網址就是唯一原因。
