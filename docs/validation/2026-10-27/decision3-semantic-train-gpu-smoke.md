# Decision3：semantic TRAIN-only GPU 短測

日期：2026-10-27（Asia/Taipei）。本次在 GX10 的 NVIDIA GB10 上，使用一筆 TRAIN 請求完成受監督的 GPU 捕捉與 CPU FP64 數值重算。這是數值及執行路徑短測，**不是瀏覽器任務成績、模型評分或競品比較**；結果仍標示為待外部接受，不具擬合資格。

捕捉結果記錄 `operation` 與 `click_target` 兩個增量頭均已套用，合法值數量分別為 4 和 24。固定見證的 CPU FP64 重算涵蓋 28 個合法機率值：baseline 與 GPU zero 各自的最大絕對誤差均為 **3.764970835096193e-8**，candidate 的最大絕對誤差為 **4.639951312057633e-9**。此稽核只證明所核對見證的數值一致性；它本身不證明來源、實際單次 forward 時間或任務正確性。

獨立審核記錄歷史 TRAIN 來源雜湊 **95／95** 相符，本次計畫的來源 pin **122／122** 相符；這是兩組各自核對的數量。計畫 SHA256 為 `302da7834da5262117ec5c22b9a57a39c7845b3b3979b3385c6476c5c545e5c2`，數值稽核彙總 SHA256 為 `80d4dabc654ee99417ace0067ead0564599ee50a126881c6105b4263c9b48a32`。原始請求、回應及逐題資料不包含於本文件。

外層監督的 54 次主機取樣涵蓋 GPU lease 起訖，各次觀察的 ComfyUI 佇列均為 idle、可用記憶體均達計畫門檻；最長相鄰取樣間隔約 0.521 秒。這些是離散取樣，不能證明間隙內狀態。本次使用獨立 lease，沒有全域互斥保證。worker 回報 CUDA allocated bytes 初末均為零並以狀態碼 0 結束；同一 invocation 的保留 unit 主 PID 為 0、cgroup 已不存在。這些結果不代表整台機器的 GPU 或共享記憶體歸零。

本次未使用 DEV 或 heldout 評測，不能據此推論真實瀏覽器完成率、泛化能力、速度優勢或正式榜單表現。尚需另行完成受監督的瀏覽器任務評測和可比較的對照，才能評估這兩個增量頭對實際可用性的影響。
