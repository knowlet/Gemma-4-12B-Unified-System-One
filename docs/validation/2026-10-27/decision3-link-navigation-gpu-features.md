# Decision3：跨文件連結資料的 GX10 特徵擷取

日期：2026-10-27

對[已重播的 72 筆 train-only 瀏覽器請求](decision3-link-navigation-collection.md)，使用固定版本 `vllm-sr/d3-edge` 在 GX10 執行真實原生 GPU 前向，分兩個獨立批次各處理 36 筆。模型收到完整原始請求；教師標籤及訓練遮罩沒有送入模型。執行器使用五核心、8 GiB 上限、零 swap 與 120 秒期限，並在獨立父程序持續監測 ComfyUI 排程及可用記憶體，沒有中止或修改其他任務。

每批執行結束後，另一個受限 CPU 程序核對工作單元與 cgroup 關閉、原始請求、固定 W0、同次前向特徵、原生回應及所有合法機率，再以 FP64 重算。兩批分別核對 36 筆、72 個 head、366 個合法機率，以及 36 筆、72 個 head、399 個合法機率；最大機率絕對誤差分別為 `1.4555881205913224e-7` 與 `1.8815626334767188e-7`。兩批 GPU 程序結束時的 CUDA 配置均回到零。

兩個重算紀錄的 SHA256 分別為 `ca53509ff47f3ad5fa95d6f83f53f19c567dd29cec2ea77375d8a016e360eba8` 及 `9c419510d28e98a6da73aefafd57a7bdfac6f311c8931016fbb8d2cf5ecfa924`。先前一筆真實 GPU 短測的重算紀錄為 `8b88bcc78d9abfba671c281a31a617a797c7980e80ba51a5af3bd8c7322fd483`；它是流程驗證，沒有加入上述 72 筆計數。

資料仍保留待合併與訓練核對的狀態。這些數字驗證特徵與原生機率的對應，並不是瀏覽器任務成功率、JevBench 分數或模型勝出的證據。
