# 通用 DONE 覆核：來源與測試狀態

日期：2026-10-27。新增的可選覆核只在 agent 以當前頁面決定 DONE 後執行，依同一目標、頁面和近期操作，要求 policy 回答 supported、unsupported 或 unknown。僅 supported 繼續原本 DONE；其他結果會在原動作選項中排除 DONE 後重新決策。失敗、逾時、資料不符或超過額外呼叫限額時不宣稱成功。原本的動作驗證、預算與 judge 仍適用。

覆核 owner 與 bridge 仍是 source-only；候選執行鏈的 gate-only 副本及配對計畫僅供獨立審查。覆核與現有 progress advisory owner 目前不相容，不能同時啟用。這個覆核使用同一 policy 端點；在 Decision3 語意候選中，覆核題目使用原生通用輸出，並未套用兩個瀏覽器增量頭。模型自評與請求雜湊都不能證明任務完成；最終結果仍須由原 judge 和獨立證據核對。

預定的單案例候選服務仍沿用 16 次請求上限；覆核和重選也會消耗該額度。到達上限可能使這次診斷提前停止，不能將中止視為通過。

在不啟動 GPU、瀏覽器或讀取評測案例的條件下，21 項合成測試通過，涵蓋一次性決策、陳舊頁面、失敗、呼叫預算、同步重入、停用時原樣委派，以及透過既有 runner 與 HTTPX mock 的 private capture 接線。成功覆核與重選的事件含有界 canonical JSON 請求和回應雜湊；這些雜湊需與 runner 紀錄、client capture 和服務綁定逐筆對帳。未匹配、遮罩不一致、重複或傳輸失敗不能推論為成功或零失敗。

獨立對帳工具另有 23 項合成測試通過，可讀取單一私有執行目錄並產生彙總。對帳一致只代表提供的紀錄一致；來源完整性、FP64 見證、程序關閉及原 judge 仍須另行驗證。沒有觀察到覆核事件時，不能宣稱覆核通過。

這些結果僅驗證合成接線與保護條件；尚無 DONE 覆核的真實瀏覽器成績，不能視為泛化能力、完整 benchmark 分數或排行榜結果。
