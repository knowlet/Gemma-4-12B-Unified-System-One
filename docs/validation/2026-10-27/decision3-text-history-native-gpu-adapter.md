# Decision3 text-history：原生 GPU adapter 診斷

日期：2026-10-27

接續[原生 GPU 投影診斷](decision3-text-history-native-gpu-projection.md)，本次在 GX10 實際呼叫雙頭 adapter：先以兩個零增量執行一筆控制請求，再以新 393／65 候選執行三筆訓練請求。四次呼叫各自完成原生前向，並經過完整的原生回應、投影、回應正規化與事件流程。兩個新增量由 CPU 傳至 GPU 後均核對了 FP32 位元組；結束時 CUDA 張量配置為零。

雙零控制的完整原生回應保持一致；候選呼叫中，未調整 head 的原生回應保持一致。獨立 CPU 程序以同次前向特徵和 FP64 重新計算原生與 adapter 回應，共核對 32 個回應 head、288 個合法機率、32 個選項及 32 個 entropy 信心值。最大機率絕對誤差為 `2.1521308518623883e-7`，最大信心值絕對誤差為 `1.062754356739859e-7`。adapter 的資料規模、必要證據欄位與雙零／候選區別另通過四項合成合約測試。

原始呼叫紀錄 SHA256 為 `576329fa773b571f7c6109ef43c510937492ef5e58110dbe984b92f3cc516d1e`，獨立重算紀錄為 `2479dccd310aef41c05f49b3aaca4b085894830f6735f1224d0fa115a1a3e0fa`。訓練紀錄引用包含輸入快照的雜湊，不是完整快照檔。這四次呼叫均使用訓練資料；本次尚未執行 HTTP 服務、瀏覽器任務或兩套 JevBench，不能據此宣稱真實任務成功或優於其他模型。
