# Decision3 text-history：GX10 分批特徵擷取

日期：2026-10-27

以 [text-history 瀏覽器收集資料](decision3-text-history-native-collection.md)為輸入，在 GX10 上完成三次獨立的模型特徵擷取。每批包含 40 筆原生請求、160 個決策 head；各批均已完成獨立 FP64 數值重播及其受限執行程序的關閉驗證。

| 批次 | FP64 重播的合法選項數 | 最大機率絕對誤差 | 最大信心值絕對誤差 |
| --- | ---: | ---: | ---: |
| 1 | 1,388 | 3.6674371750589074e-7 | 1.8164646342633262e-7 |
| 2 | 1,626 | 4.720813903125176e-7 | 2.393358309316085e-7 |
| 3 | 1,868 | 2.8046953692850707e-7 | 1.786872333431333e-7 |

三批使用的原始讀出權重雜湊一致；擷取期間沒有載入教師標籤，也沒有訓練模型。這些結果證明各批擷取的數值可供後續核對，並不構成模型表現分數。

跨批獨立稽核已重讀原始資料，確認三批依原始順序完整涵蓋 120 筆，沒有重複或遺漏；合計重播 480 個 head、4,882 個合法選項，並重新驗證 596 個讀取檔案的身分。彙整報告 SHA256 為 `8499ca2534c1f25e259591826943aaa7a9e6af53ea98069c1faa18303a1a21e1`。本次驗收僅涵蓋訓練資料的特徵擷取與數值一致性。

模型、瀏覽器及評測分數目前均為 null；後續仍需接合操作標籤、訓練，以及真實瀏覽器和兩套 JevBench 的評測，才能判斷實際成效。
