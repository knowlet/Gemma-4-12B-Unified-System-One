# Decision3 text-history：原生 GPU 雙頭投影診斷

日期：2026-10-27

在 GX10 載入固定版本的 d3-edge，以三筆已收集的訓練請求執行真實原生 GPU 前向推論，從同一次前向擷取特徵，並將[新候選](decision3-text-history-cpu-fit.md)的 operation 與 click-target 增量分別套到對應 head。每個請求保留原有四個 head 與其合法選項；另外以兩個零增量在同一次前向特徵上投影，核對基礎模型的原生機率。兩份增量的 CPU 到 GPU 資料位元組均已核對。

獨立 CPU 程序以 FP64 重算三筆請求、12 個 head、109 個合法選項；原生、零增量和新候選投影各自的機率與最大值選項均符合重算結果，共 36 次最大值選項檢查。最大機率絕對誤差分別為 `9.58e-8`、`1.20e-7`、`2.07e-7`。未調整 head 的重播 logits 維持位元組一致。GPU 程序結束時已清理 CUDA 工作區，張量配置回到零；獨立重算程序也正常結束。

第一次有載入模型的嘗試完成三筆前向，但因未清除 CUDA 工作區而未通過結束時檢查；上述結果來自另一次完整成功的執行。原生輸出紀錄 SHA256 為 `6d628450ab7b17b29c4fa8adf88ba6a1a6af1b27a1772cd80ca8bce3a492c3aa`，獨立重算紀錄為 `a05dfd01c555a0652a6319420139fd9b6226e1342b2a7e802cd13008ed1e789d`。

此次驗證的是原生前向後的 GPU 投影，**尚未執行完整雙頭 adapter 服務、瀏覽器任務或兩套 JevBench**。三筆均為訓練資料，也未核對原生信心值；結果不代表任務成功、模型泛化或勝過其他模型。
