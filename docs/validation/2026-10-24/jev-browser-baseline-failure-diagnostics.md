# 高跑分與瀏覽器可用性：本輪已確認的落差

Gemma 的新瀏覽器單邊測試成功 **3/10**。七題失敗分為：

| 原始結果 | 題數 |
| --- | --- |
| 宣告完成，但原始任務驗證未通過 | 2 |
| 以 blocked 結束，目標未達成 | 3 |
| 用盡原定 16 次決策，目標仍未達成 | 2 |

這十題共呼叫策略模型 82 次、文字 helper 6 次；捕捉到的 **88 次 HTTP
請求全部回傳 200**。因此，模型服務能正常回答，仍不足以代表它能完成
多步網頁任務。尤其五次宣告完成中只有三次經任務驗證成功；提前結束是
已確認的問題。三個 blocked 案例的原因仍需逐步紀錄釐清，尚未全部歸因。

Benchmark Heaven 的分類準確度、JevBench 的機率一致性，以及瀏覽器的
多步任務成功率，使用不同任務與驗收條件。本輪原始 Decision3 Edge 的
68.3983% 準確度與 70.5866/100 一致性分數，不能替代新 operation 候選
模型的瀏覽器測試。

下一輪維持原始 judge、16 步預算及完整失敗分母，優先驗證操作是否持續
推進目標，以及何時應宣告完成。這份診斷只彙整已觀察到的失敗；未將
評測快照或原始判分資料加入訓練，也未建立完整 Decision3 瀏覽器分數。
